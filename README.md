# ResourceStats
The Resource Stats Gem provides various resources, stats, and metrics for your game's characters.

O3DE ResourceStats Gem is licensed under [MIT](LICENSE.txt).

## Adding a new Resource / Stat
Simply run `addstat.sh` in a Bash shell and follow its instructions to create a new resource / stat.

## Installation Instructions
You can install this gem in your project using O3DE's project manager. Navigate to the Gem Repositories page and provide this URL:

`https://gitlab.com/porcupine-factory/ResourceStats/-/raw/main`

Alternatively, clone this repo, register the gem with `scripts\o3de register --gem-path <path-to-gem>`, and enable it in your project.
